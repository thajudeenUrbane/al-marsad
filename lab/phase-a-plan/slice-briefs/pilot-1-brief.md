# Pilot 1 brief — does the world teach better than the page?

Context: lab/beyond-the-graph (N6; experiments 1, 2, 4, 9; sample sizes); docs/handover/maintainer-answers-3.md (E1, E2); lab/phase-a-plan/PLAN.md (Gate A1, weeks W2–W12). Do not read chat history; this file is the brief. Owner: the learning researcher, with the maintainer.

## Design
- **Within-person, counterbalanced.** Each learner does chapters 1–5 in one condition and 6–10 in the other; order and pairing are balanced. World condition: the frozen beta with guess-first and recall. Control: the reading page with the same claims, order, citations and time on task.
- **Primary outcome:** cued recall at one week (7 ± 1 days), from a test built only from claims, scored blind by two raters (κ ≥ 0.8). **Secondary:** immediate recall; one-month recall (feeds Gate B); guess-first on vs off per chapter (exp 2); 7-day return (exp 9).
- **Sample:** at least 40 completers (60 enrolled across 2–3 classes or circles). Report the paired effect size with a 95% CI; the gate is d ≥ 0.3.

## Build
1. Protocol, instruments, rubric, and an analysis script run on simulated data (`lab/pilot-1/`).
2. Parent consent, child assent, and a data plan: pilot codes only, no names in any file, raw data outside the repo; ethics review by the partner's board or an independent reviewer.
3. Preregistration filed before any data, citing the frozen build's tag and content hash.
4. Dry run (W7) with 6–10 people; fix timings and instruments, not the hypotheses.
5. Sessions (W10), one-week recall (W11), analysis and report (W12).

## Done when
Preregistration filed; ≥ 40 completers; analysis run exactly as preregistered; aggregate results and the report committed to `lab/pilot-1/`; handover `docs/handover/pilot-1.md` (≤60 lines) with the Gate A1 result and any deviations.

## Rules
No learner data in the repo; aggregate results only. Report the result whatever it is. No model names or IDs in the repo.
